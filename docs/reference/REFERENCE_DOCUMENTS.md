# 解释性文档清单

本文档用于说明哪些文档主要承担说明、交接、阶段追溯或论文答辩材料作用。它们可以帮助理解项目背景和历史，但不作为后续开发的主要工程约束。

## 1. 判定原则

解释性文档具备以下特征：

- 主要用于项目入口、交接说明、历史记录、答辩材料或操作补充。
- 可以复述当前状态，但不独立维护接口字段、数据库字段、算法公式或前端细则。
- 与约束性文档冲突时，以 `docs/constraints/CONSTRAINT_DOCUMENTS.md` 中列出的约束性文档为准。

如果解释性文档中出现与当前规则不一致的内容，应同步修正文档，不应按解释性文档直接改工程实现。

## 2. 当前解释性文档

| 文档 | 类型 | 使用方式 |
| --- | --- | --- |
| `README.md` | 项目入口和总览 | 用于快速了解项目、文档入口、本地配置和启动方式；不重复维护详细规则 |
| `docs/README.md` | 文档目录索引 | 用于了解 `docs` 下的分类目录结构 |
| `docs/reference/HANDOFF.md` | 交接说明 | 用于快速接手项目、了解当前完成状态、运行方式、常用页面和后续建议 |
| `docs/reference/IMPLEMENTATION_TASKS.md` | 阶段路线和任务历史 | 用于追溯阶段目标和里程碑，不作为当前开发合同 |
| `docs/reference/COMPLETED_PHASES.md` | 已完成阶段记录 | 用于追溯完成情况、验证结果和论文材料，不作为当前开发合同 |
| `docs/reference/DATABASE_SCRIPT_README.md` | 数据库脚本说明 | 用于解释 `schema.sql` 和 `seed-data.sql` 的用途；数据库初始化以 `docs/constraints/DATABASE_INIT.md` 为主入口 |

## 3. 当前缺失但曾被入口文档引用的说明类文档

| 文档 | 类型 | 处理口径 |
| --- | --- | --- |
| `docs/reference/DEFENSE_NOTES.md` | 论文和答辩参考材料 | 当前工作区未找到该文件；如果后续恢复，应归入解释性文档，不作为工程约束 |

## 4. 使用规则

- 新开发者可以先读 `README.md` 和 `docs/reference/HANDOFF.md` 建立项目整体认知。
- 真正开始改代码或改规则前，必须切换到 `docs/constraints/CONSTRAINT_DOCUMENTS.md` 中列出的约束性文档。
- 阶段历史只用于理解项目如何演进，不用于决定当前字段、接口、算法或数据库规则。
- 答辩材料只用于论文和演示表达，不用于定义工程实现。
